# 60秒ダンジョン(仮題)

スマホ向け見下ろしアクションRPG。1回60秒。45秒雑魚を狩り、残り15秒でボス。素材で装備を作って、次の階へ。

- 公開先: https://claude.ai/artifact/U3L3FBSfscfnEsvg1NYN51
- 本体: `index.html` (1ファイル)
- 絵: `assets/` に透過PNGを置く。無ければ図形で描く。

## 決めたこと(2026-09-26)

- 方向: ブロスタの操作感で、対戦ではなく狩りとクラフト。将来はPvP(ランクマッチまで)。
- 職業: 剣士(近接・前方の弧)、魔法使い(一閃型レーザー・貫通)。武器は職業別、レベル・素材・防具は共有。
- 攻撃: 一番近い敵を自動で狙う。長押しで連続攻撃。接触ダメージあり。
- 敵: スライム、コウモリ(突進)、射手(弾)。45秒の討伐で闘気が溜まり、ボス戦の攻撃力が上がる。
- 見た目: ドット絵(2頭身、32x32、ボス64x64、素材16x16、透過PNG、右向き)。画像はGPTで生成。
- 公開日: 2026-10-26 に未完成でも友達に送る。
